# Unemployment Analysis with Python

## Objective
To analyze unemployment trends in India using Python, exploratory data analysis, and data visualization.

## Dataset
The project uses the Unemployment in India dataset downloaded from Kaggle.

## Tasks Performed
- Loaded and inspected the dataset.
- Removed duplicate rows and completely empty rows.
- Cleaned column names and text values.
- Converted date and numeric columns to appropriate data types.
- Analyzed average unemployment rates by region.
- Examined monthly unemployment trends.
- Compared unemployment rates before and from March 2020 onward.
- Visualized unemployment trends across three regions.
- Identified the top 10 regions with the highest average unemployment rates.
- Created a correlation heatmap for unemployment, employment, and labour participation indicators.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Files
- `OIBSIP_DataScience_Task2_UnemploymentAnalysis.ipynb` — Jupyter notebook containing the analysis.
- `screenshots/` — screenshots of the charts and outputs.

## Conclusion
This project uses exploratory data analysis and visualization to study unemployment patterns in India. It examines regional differences, monthly trends, changes around the COVID-19 period, and relationships among employment indicators.
