
# Iris Flower Classification

Oasis Infobyte Data Science Internship — Task 1

## Objective
Build machine learning models to classify iris flowers into three species.

## Dataset
The built-in Iris dataset from Scikit-learn.

## Models
- Logistic Regression
- K-Nearest Neighbors

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab

## Evaluation
Accuracy, classification report, and confusion matrix.
