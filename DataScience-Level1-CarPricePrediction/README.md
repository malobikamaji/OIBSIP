# Car Price Prediction using Machine Learning

## Internship
Oasis Infobyte Data Science Internship — OIBSIP

## Objective
To develop a machine learning model that predicts car prices based on vehicle characteristics.

## Project Overview
This project uses the Car Price Prediction dataset to explore vehicle features and build regression models for estimating car prices.

## Dataset
**File:** `CarPrice_Assignment.csv`

The dataset contains information about car specifications, including fuel type, body style, engine size, horsepower, mileage, and price.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Load and inspect the dataset.
2. Clean the data and check for missing values and duplicates.
3. Perform exploratory data analysis (EDA).
4. Prepare features and encode categorical variables.
5. Split the data into training and testing sets.
6. Train Linear Regression and Random Forest Regressor models.
7. Evaluate models using MAE, RMSE, and R² Score.
8. Compare actual and predicted car prices.

## Models Used
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Coefficient of Determination

## Results
The models are compared using the evaluation metrics. The model with lower MAE and RMSE and a stronger R² Score is generally preferred, considering the overall results.

## Conclusion
This project demonstrates how regression models can be used to estimate car prices based on vehicle features. Exploratory data analysis and model evaluation help assess the usefulness of the predictions.
